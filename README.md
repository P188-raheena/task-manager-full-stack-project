# Task Manager – Full Stack Web Application

A full-stack Task Manager application that allows users to securely manage their daily tasks. Users can register, log in, create tasks, update them, mark them as completed, and delete them.

## 🚀 Features

* User Registration and Login
* User Authentication
* Create new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* View and manage tasks
* Responsive user interface
* REST API integration
* MongoDB database

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/P188-raheena/task-manager-full-stack.git
```

### 2. Open the project

```bash
cd task-manager-full-stack
```

### 3. Install dependencies

Open the required frontend/backend folders and install the dependencies:

```bash
npm install
```

### 4. Start the application

Run the frontend and backend according to the project configuration.

## 🗄️ Database

The application uses MongoDB to store user and task information.

Make sure MongoDB is running and configure the required database connection in the project.
