# Task-manager-task
📋 Task Manager – Full Stack Web Application

A responsive and user-friendly Task Manager application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js). This project allows users to create, update, delete, and manage daily tasks efficiently with secure backend integration and a modern UI.

🚀 Features

- User Authentication
- Add, Edit & Delete Tasks
- Mark Tasks as Completed
- Responsive Design
- REST API Integration
- MongoDB Database Support

🛠️ Tech Stack

React.js | Node.js | Express.js | MongoDB
